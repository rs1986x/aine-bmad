# Deferred Work

reviewing story's job. Most are accepted trade-offs recorded with their
reasoning so a later review does not re-litigate a decision already made.

Conventions: entries are grouped by the review that raised them, ~~struck
through~~ with a **RESOLVED in Story X** note once delivered, and annotated
**RE-POINTED** when an entry named a target story that shipped without it.

- No graceful shutdown — no `SIGTERM`/`SIGINT` handler calling `pool.end()`, so in-flight requests/connections are dropped on container stop. Foundation scope; add when deployment topology is finalized. [backend/src/index.ts]

Works in CI and with local `.env.test`; refactor (lazy singleton / split pure module) deferred as the approach is not clear-cut. [backend/src/config/env.ts]
